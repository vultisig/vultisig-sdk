Publish `getBlockchairBaseUrl` (chain-scoped `${rootApiUrl}/blockchair/${chain}` URL builder) from the SDK's public surface. It already existed as SDK core's canonical Blockchair proxy-URL helper and is used internally by the UTXO status/broadcast resolvers, but was not re-exported from `@vultisig/sdk`, so first-party consumers (app, agent-backend) had to reconstruct the same path locally instead of importing one tested contract.
