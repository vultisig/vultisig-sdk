Export `getSplAssociatedAccount` from both the root SDK entry and `@vultisig/sdk/react-native`. `buildSplTransfer` requires a caller-supplied `isToken2022` flag documented as fund-safety-critical (passing `false` for an actual Token-2022 mint derives the wrong ATA/program id — a failed tx or, worse, a credit to an unintended account), but the SDK published no canonical resolver for it, pushing consumers toward deep-imports or reimplementing Solana token-program detection. The underlying helper already existed internally (including an RN/Hermes-safe override already wired through `rollup.platforms.config.js`'s `rnOverrideMap`) but was never a stable public export.
