Add a guard test pinning the THORChain/MayaChain pool asset ticker for every native-swap-enabled chain against an independent oracle table (not derived from `chainFeeCoin`). `toNativeSwapAsset`'s fee-coin branch interpolates `chainFeeCoin[chain].ticker` directly into the protocol asset string (e.g. `BSC.BNB`), but that ticker is a display value that can be rebranded (as Toncoin's became `GRAM`), while the pool asset symbol is protocol-stable. If a native-swap chain's fee-coin ticker is ever added or rebranded without matching the actual pool asset, this test fails at build/test time instead of the mismatch surfacing as a silent wrong-asset string at quote time.
