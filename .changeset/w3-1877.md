Fix `getTrxBalance` silently rounding TRON whale balances above `Number.MAX_SAFE_INTEGER` SUN (~9.007M TRX). The TRON RPC returns `balance` as a JSON number, and `JSON.parse` already rounds it once the value exceeds 2^53 before any of our own code runs, so parsing it as a plain `number` was deterministic precision loss. `getTrxBalance` now fetches the raw response text (via a new `fetchJsonWithText` helper in `rpc.ts`) and recovers the exact SUN integer with a regex + `BigInt`, mirroring the same pattern already used for XRP drops and Solana lamports. The result exposes both `balanceSun` (a `number | null` convenience mirror, `null` when unsafe to represent) and a new `balanceSunRaw` (lossless base-10 string), and `balanceTrx` is now always formatted from the exact integer.
