'@vultisig/sdk': patch
---

Stop forcing spurious major bumps on `@vultisig/rujira` (and any other peer-dependent package) every time the SDK releases a patch or minor. Changesets' default treats any peer-dependency version change as breaking for the dependent, so 61 of `@vultisig/rujira`'s last 64 published versions were majors despite the peer range (`>=4.5.0`) never actually being violated. Setting `onlyUpdatePeerDependentsWhenOutOfRange: true` in `.changeset/config.json` makes the peer-dependent bump conditional on the range genuinely being out of date, so a rujira major now only fires when its declared SDK peer range is actually moved.
