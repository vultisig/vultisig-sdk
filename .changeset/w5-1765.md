Adds a batched, multi-network StakeKit balances helper (`fetchAllStakekitBalances`, `fetchStakekitBalancesBatch`, `chunkStakekitBalanceQueries`) exported from `@vultisig/sdk`'s stakekit defi builders. Queries `{network, address}` pairs directly across any number of networks, batched at the yield.xyz-enforced cap of 25 per request — unlike the existing single-network `stakekitBalances`, which requires a per-network `searchYields` round trip to enumerate yield IDs first. A single failing batch doesn't abort the others (partial data survives), but the whole call throws if every batch fails so a caller doesn't cache an empty result as a false positive. Previously this only existed as `vultiagent-app`'s local `yieldXyzPositions.ts` positions client.
