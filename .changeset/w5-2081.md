`findSwapQuote`/`findSwapQuotes` now expose a `comparableOutputAmount` field on every returned `BoundSwapQuote` — the same destination-base-unit, fee-normalized output amount the SDK's own best-quote ranking already computes — so consumers no longer need to reimplement native THOR/Maya precision conversion or general-provider destination-fee subtraction themselves. `SwapError` also gained an optional `metadata.nativeMin` field carrying the structured `{ swapChain, minAmountInBaseUnits, minAmountInHuman }` threshold when a THORChain below-minimum rejection is thrown and that protocol minimum is available; otherwise `metadata.nativeMin` remains undefined, so a below-minimum swap no longer requires a second native-quote fetch just to recover the actionable minimum when the SDK already knows it.
