Several shared RN-exported balance helpers (`tools/balance/rpc.ts`'s `fetchJson`, `cosmos.ts`, `utxoBalance.ts`, and `bittensor.ts`) called `AbortSignal.timeout` directly, which doesn't exist on older RN/Hermes runtimes and can make balance reads fail on those environments even though the SDK already carries a Hermes-safe `AbortController` + `setTimeout` timeout pattern elsewhere (e.g. `chains/tron/rpc.ts`, `tools/gas/utxoFeeRate.ts`, `tools/balance/polkadot.ts`'s use of `queryUrl`). Routed all four through the same Hermes-safe pattern, preserving each file's existing retry/HTTP semantics exactly (including `fetchJson`'s caller-signal precedence and `cosmos.ts`'s `TimeoutError`-name-based retry check).
