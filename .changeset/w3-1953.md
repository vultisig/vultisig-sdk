Extract one canonical yield.xyz/StakeKit network-slug -> Vultisig chain mapping (`yieldNetworkToCanonicalChain`) into a new shared module (`tools/defi/stakekit/yieldNetworkChain.ts`), replacing the two private duplicate switch tables that had drifted inside the SDK (`yieldNetworkToCanonicalChain` in `stakekit/index.ts`, `yieldNetworkToEvmChain` in `stakekit/stakekitApi.ts`). Export it from the root SDK entrypoint so app/backend consumers can import the canonical helper instead of growing their own copy. `yieldNetworkToEvmChain` (used to build EVM-shaped scan requests) is now a thin EVM-only wrapper derived from the canonical mapping, preserving its existing fail-closed behavior for non-EVM networks — no behavior change for either call site.
