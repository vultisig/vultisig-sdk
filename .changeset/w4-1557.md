Export the Jupiter (Solana same-chain swap) helper family from `@vultisig/sdk/react-native`, matching what the root SDK entry already exposes: `SOL_NATIVE_MINT`, `JUPITER_AFFILIATE_FEE_OWNER`, `JUPITER_PLATFORM_FEE_BPS`, `JUPITER_API_BASE_URL`, `JUPITER_DEFAULT_SLIPPAGE_BPS`, `JUPITER_AFFILIATE_FEE_ATAS`, `JupiterAffiliateConfig`, and lazy `buildJupiterSwapTx` / `resolveJupiterFeeAccount` wrappers. Split the plain config constants out of `tools/swap/jupiter.ts` (which eagerly imports `@solana/web3.js`) into a new dependency-light `tools/swap/jupiterConfig.ts` so RN can statically re-export them without pulling `@solana/web3.js` into the eager bundle graph; `buildJupiterSwapTx`/`resolveJupiterFeeAccount` are exposed via `await import(...)` wrappers, mirroring the existing `buildSplTransfer` pattern. Previously RN consumers (Station) had no canonical import path for the SDK-owned same-chain Solana swap builder and were pushed toward local Jupiter wiring.
