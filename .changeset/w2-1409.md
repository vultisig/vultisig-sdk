`packages/sdk/src/tools/prep/index.ts` was already the canonical vault-free tx-builder barrel, but `@vultisig/sdk` didn't publish a `./tools/prep` package subpath — first-party consumers wanting only deterministic tx builders had to import the full root surface or deep-import internals. Published `@vultisig/sdk/tools/prep` the same way as the existing `./tools/parse` / `./tools/defi` / `./tools/bridge` / `./tools/balance` / `./tools/decode` subpaths: an export-map entry in `package.json`, a dedicated JS bundle in `rollup.platforms.config.js`, a dedicated `.d.ts` bundle in `rollup.types.config.js`, and coverage extended in the public-API subpath regression test and the packed-tarball smoke script.
