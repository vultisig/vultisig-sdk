The SDK's chain-agnostic raw-broadcast implementation (`RawBroadcastService`, covering EVM/UTXO/Solana/Cosmos/TON/Polkadot/Bittensor/Ripple/Sui/TRON) was only reachable through `VaultBase.broadcastRawTx`, forcing runtimes that already hold signed raw bytes to stand up vault plumbing (or their own submitter) just to broadcast. `RawBroadcastService` holds no vault state, so it is now also exposed as a standalone `broadcastRawTx` export from the SDK root, backed by the same broadcaster; `VaultBase.broadcastRawTx` remains a thin wrapper that additionally emits vault events.
