Scope the StakeKit `/yields/enabled` cache by API key. `/yields/enabled` returns only the yield products the calling project's API key is allowed to deposit into, but the SDK cached responses under a query-only key with no auth scope. In a shared SDK process, one caller warming the cache could cause a later caller with a different (or no) API key to receive the wrong enabled-yield set — both correctness drift and cross-tenant leakage of product visibility. Cache entries now key on `apiKey ?? 'public'` alongside the query string.
