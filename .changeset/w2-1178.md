The React Native EVM fee helper (`getEvmSuggestedFees`) computed `maxPriorityFeePerGas` as naive `baseFee / 10` with no floor, so a quiet-block RPC quote could collapse toward zero and leave a signed tx sitting unmined in the public mempool — the same class of bug the app and backend already hotfixed with their own per-chain minimum-tip tables. The SDK already publishes a canonical per-chain floor/ceiling policy (`clampEvmPriorityFee`) but the RN fee helper never called it. Wired `getEvmSuggestedFees` through `clampEvmPriorityFee`, so its priority fee is floored (Ethereum 1 gwei, Polygon 30 gwei) and sanity-ceilinged against an anomalous RPC quote, same as any other first-party consumer of that helper.
