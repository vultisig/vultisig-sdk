Export the canonical XRP destination/X-address normalization helpers (`decodeRippleXAddress`, `encodeRippleXAddress`, `isValidRippleXAddress`, `normalizeRippleDestination`, `RippleDestination`) from both the root `@vultisig/sdk` and `@vultisig/sdk/react-native` entrypoints. These already existed as pure SDK-core helpers and are already bundled into the RN platform build (via the XRP send-tx builder), but were not part of the public package surfaces, so first-party consumers had to deep-import `@vultisig/core-chain/chains/ripple/address` instead of staying on the SDK boundary. The CLI's `transaction.ts` now imports `normalizeRippleDestination` from `@vultisig/sdk`.
