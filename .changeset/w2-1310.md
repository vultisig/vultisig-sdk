`packages/sdk/src/tools/policy/types.ts` documents the canonical bytes-oracle decoder as `sdk.decode.fromToolResult`, but `@vultisig/sdk` only ever exported flat helpers (`decodeFromToolResult`, `decodeCosmosTx`, `decodeEvmTx`) — `sdk.decode` was `undefined`, so the docs and the runtime surface disagreed. Added a `decode` namespace object (`{ fromToolResult, decodeCosmosTx, decodeEvmTx }`, aliasing the existing flat helpers) exported from `tools/decode/index.ts` and re-exported through `tools/index.ts`, the root `index.ts`, and the React Native entrypoint.
