Re-export the canonical Cosmos Tendermint/Stargate RPC registry (`tendermintRpcUrl`) from both the root SDK entry (`packages/sdk/src/index.ts`) and the React Native entry (`packages/sdk/src/platforms/react-native/index.ts`). The core package already used this table for `StargateClient.connect(...)`, and the SDK already surfaced the adjacent Cosmos REST registry (`cosmosRpcUrl`), but downstream consumers needing an actual CosmJS/Stargate RPC connection had no public SDK import for it and were pushed toward mirroring a second local endpoint table.
