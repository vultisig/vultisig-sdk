Fix `SwapService.extractFees` silently dropping the Vultisig affiliate fee for EVM aggregator routes (it never read `tx.evm.affiliateFee` at all) and for Solana routes (it folded the swap fee into `total` but never surfaced it as `affiliate`), so `SwapQuoteBase.fees.affiliate` is now populated whenever the aggregator returns a fee priced in the source chain's native token. Non-native-denominated affiliate/swap fees are left off both fields rather than being unsafely summed into a native-unit total. Extracted the fee-derivation logic into a standalone, unit-tested `extractSwapFees` helper.
