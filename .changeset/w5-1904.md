Exports `finalizeStakekitAction` (and its supporting `honestStakekitBuildFailureMessage`/`sanitizeStakekitRejectionReason` helpers) from `@vultisig/sdk`'s StakeKit builder surface — a canonical final acceptance/refusal gate that classifies a `YieldActionResponse` into `signable | provider_error | unsignable_sui | unsupported_chain | incomplete` before a consumer hands it to a wallet for signing. Previously this decision (permanent provider build rejection, unsignable Sui JSON-intent payloads, chains with no SDK signer, incomplete async builds) lived only in `agent-backend-ts`'s local `finalizeYieldAction`, so any other SDK consumer had to reimplement it or risk surfacing incomplete/unsupported provider output as signable. `YieldTransaction` also gained an optional `buildError` field, populated by the existing async-build PATCH loop when the provider permanently rejects a build (e.g. an on-chain MoveAbort).
